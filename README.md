DI501_EdaOnay_InterimPhase_2739415

My repository contains my interim phase materials for our DI 501 term project based on the SpotGenTrack dataset.

Research Questions:
1. To what extent can a song’s release decade be predicted using Spotify audio features and Genius lyric-complexity features in a multi-class classification setting?
2. Is there a statistically significant difference between older and modern songs in terms of their mean "acousticnes" and "energy" values?

My Repository Structure
- `articles/`: literature used in the report
- `data/`: dataset files
- `notebooks/`: Jupyter notebook used for preprocessing and analysis
- `reports/`: interim report files (both PDF and word)
- `figures/`: figures used in the report
- `generated csv files/`: generated descriptive tables and outputs
- `requirements.txt`: required Python packages

Notes:
The notebook uses relative paths so that the project can be executed within this folder structure on different operating systems (this project was done with MacOS)
